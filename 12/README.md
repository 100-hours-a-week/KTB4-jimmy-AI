# 12주차 과제 — vLLM 서빙

1. 개인 프로젝트에 쓰이는 공개 가중치 모델을 vLLM으로 서빙해 보세요.  
    gpu 활용이 핵심인 것 같은데 잘 활용하지 못했다. 특히 GGUF 로딩하려면 플러그인을 사용해야 했고 colab에서 해서 백그라운드 프로세스로 띄워서 OpenAI 호환 API 직접 호출을 테스트해야 했고, 서버도 잘 안떠서 고생했다.
    ipynb 노트북 작성에 관해선 llm에게 부탁했다. 중간에 백그라운드 프로세스로 띄우는 부분은 아직 이해 못했다. 좀 더 봐야 될 듯.
    벤치마킹같은 evaluate를 안해봤고, 성능이 뛰어난 모델이나 좋은 eval 도구가 있던게 아니였기 때문에, 그냥 배포해봤다로 그친 것 같다. 나중에 여유가 되면(한국식 약속) 한번 eval해보고 싶다. 애초에 gpu를 쓰는데 지금 레벨에서 느릴수가 있을까?
    
2. (선택) 서빙 엔진을 Docker 컨테이너로 패키징하고 EC2 환경에 배포해 보세요.
