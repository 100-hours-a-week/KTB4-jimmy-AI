# 명언 디스펜서

지금은 랜덤이지만 나중에 ai로 자신 상황 설명하면 상황에 맞는 명언 주기

지금은 마크다운이지만 나중에 db랑 연결하기
	나중에 플레이리스트, 선택한것들 따로 마크다운으로 출력 가능
	포멧에 맞는 마크다운 출력하기
	마크다운 템플릿 출력하기(주석 자세히)

수동으로 태그 먹이기/자동으로 ai가 태그 먹이기

나중에 웹 서비스 배우면 회원가입/로그인으로 설정 저장하기

	남들과 내 명언 공유

	명언 집어넣는 기능

	나왔던 명언, 날짜 기록, 보여주기 기능

	중복on off, 셔플 on off기능(뮤직 앱 처럼)

		중복x은 한번씩 다돌고 알려주기, 중복o는 독립시행

	명언 플레이리스트로 마음에 드는 명언 따로 분류(태그 말고)

	명언 즐겨찾기(플리랑 다름)

		즐겨찾기 플리 자동생성

	들어올 떄 자동으로 명언 뽑기 on off

	명언에 따봉 날리기

3개 한번에 뽑기

태그별로 뽑기

지은이 검색

전체 태그 목록 검색

명언 검색

전체 명언 출력

영어공부를 위한 영어 버전→한글 번역보기

---

## 일단 어디까지 구현?

- 마크다운의 명언 읽어오기(cli)
	- 랜덤으로 명언 하나 출력
	- 태그별 뽑기
	- 저자별 뽑기
	- 3개 동시에 뽑기
	- 전체 명언 목록 출력
		- 전체 태그 목록 출력
- 터미널에서 명령어로 실행할 수 있다
  ```
  python cli.py             # 랜덤 1개
  python cli.py --tag 동기부여
  python cli.py --author 공자
  python cli.py --count 3
  python cli.py --all
  python cli.py --tags
  ```

## 2단계

- 중복 / 셔플 설정 (뮤직 앱 방식)
	- 중복 OFF: 모든 명언을 한 번씩 다 보여준 뒤 알림
	- 중복 ON: 독립 시행 (같은 명언이 연속으로 나올 수 있음)
	- 셔플 ON/OFF

- 명언 이력 기록
	- 뽑은 명언과 날짜를 파일에 기록한다
	- 이력 조회 기능
	- 조회수 표시 기능(내가 이걸 몇번 뽑았나)
		- 보면 실시간으로 조회수 올라가서 조회수 기능 직관적으로 이해시키기

- 영어 명언-한글로 전환 설정

- 명언 검색, 필터링
	- 좋아요, 지은이, 태그, 등록자, 들어가는 단어, 조회수 and/or 필터링<-노션 기능 참고

- GUI 만들기(웹 서비스 고려)

---

## 웹 서비스

- 회원가입/로그인

- 사용자별 설정 저장

- 사용자가 새 명언을 직접 등록
	- 다른 사용자와 명언 공유
	- 등록자 표시

- 따봉 기능
	- 명언에 좋아요를 누를 수 있다
	- 좋아요 많은 순 정렬

- db 연동
	- 현재 마크다운 파일->데이터베이스로 마이그레이션
	- db의 명언들 골라서 마크다운으로 다운로드
		- 필터링해서 원하는 것들만 체크해서 다운로드
	- 템플릿만 다운로드

---

## 심화 기능

- 마크다운 템플릿 수정

- 자동 뽑기 on/off
	- 앱 실행 시 자동으로 명언 1개 출력 여부 설정

- 즐겨찾기, 플레이리스트
	- 마음에 드는 명언을 즐겨찾기에 추가
	- 즐겨찾기 목록 자동으로 플레이리스트 생성
	- 명언을 직접 분류해서 나만의 플레이리스트 만들기
	- 즐겨찾기와 별개로 운영
