# 명언 디스펜서
---
# How to use

  ```
	python3 cli.py   :랜덤 명언카드 하나 뽑기
	python3 cli.py n :n개 뽑기                    
	python3 cli.py --idx idx :인덱스로 명어카드 찾기
	python3 cli.py --all :전체 카탈로그 보기
	python3 cli.py --help    :도움말 출력
  ```

# 개발 로드맵
---

## 1단계

- 마크다운의 명언 읽어오기
	- 랜덤으로 명언 하나 출력
	- 태그별 뽑기
	- 저자별 뽑기
	- 3개 동시에 뽑기
	- 전체 명언 목록 출력
	- 전체 태그 목록 출력
- 터미널에서 명령어로 실행할 수 있다(cli)

---

## 2단계

- 중복 / 셔플 설정 (뮤직 앱 방식)
	- 중복 OFF: 모든 명언을 한 번씩 다 보여준 뒤 알림
	- 중복 ON: 독립 시행 (같은 명언이 연속으로 나올 수 있음)
	- 셔플 ON/OFF

- 명언 이력 기록
	- 뽑은 명언과 날짜를 파일에 기록한다
	- 이력 조회 기능
	- 조회수 표시 기능(내가 이걸 몇번 뽑았나)
		- 보면 실시간으로 조회수 올라가서 조회수 기능 직관적으로 이해시키기

- 영어 명언-한글로 전환해서 보기(뽑힌 명언에서)
	- 기본언어를 설정하고, 그 언어만 뽑히도록 하는게 기본 설정
	- 한글로 설정했는데 한글 버전이 없고 영어버전만 있을 때 그냥 영어버전도 뽑힐 수 있게 하는 작동방식 설정 추가

- 명언 검색, 필터링
	- 좋아요, 지은이, 태그, 등록자, 들어가는 단어, 언어(영어/한글), 조회수 and/or 필터링<-노션 기능 참고

---

## 웹 서비스

- 회원가입/로그인

- db 연동
	- 마크다운 파일->데이터베이스로 마이그레이션 (기본 템플릿만 가능)
	- db의 명언들 골라서 마크다운으로 다운로드
		- 필터링해서 원하는 것들만 체크해서 다운로드
	- 템플릿만 다운로드

- 사용자별 설정 저장

- 사용자가 새 명언을 직접 등록
	- 나만의 명언 페이지(내가 등록한 명언들)
	- 다른 사용자와 명언 공유
	- 등록자 표시

- 따봉 기능
	- 명언에 좋아요를 누를 수 있다
	- 좋아요 많은 순 정렬

---

## 심화 기능

- 마크다운 템플릿 수정
	- 수정한 템플릿 올리면 한번에 등록

- 자동 뽑기 on/off
	- 앱 실행 시 자동으로 명언 1개 출력 여부 설정

- 즐겨찾기, 카드 덱(플레이리스트)
	- 마음에 드는 명언을 즐겨찾기에 추가
	- 즐겨찾기 목록 자동으로 덱 생성
	- 명언을 직접 분류해서 나만의 덱 만들기
	- 즐겨찾기와 별개로 운영
	- 덱 공유

- GUI 만들기

- 영어 버전 볼 때 올리면 뜻 해석/ 전체 영어버전 번역

- 댓글 쓰기

- 명언 등록한 날짜 표시

- 덱, 카드 컨셉 / 플레이리스트, 노래 컨셉 / 명언집, 명언 컨셉 전환

---

## AI 기능

- 현재 내 상태 서술하면 AI가 판단해서 태그 추천해서 뽑아주기
- 명언 등록하면 태그 추천해주기
- 비슷한 명언 찾기, 묶기(가장 좋아요 높은것만 표시, 나머지는 토글목록으로)

# 어떻게 구현?

- Template.md과 같은 형식을 기준으로 파싱 규칙 구축
	- 유저가 수정할 수 있는 Template_user.md와 분리(출력용) 
- quotes.md 파일을 Template.md 형식을 기준으로 작성
- base.py에서 기본 class들, Template.md 형식을 기준으로 읽기
- cli에서 마크다운의 명언 읽어오기(cli)
- 변수명
	- 전체 카드 목록은 catalog
	- 플레이리스트는 deck
	- 카드 하나는 quotecard
	- dispenser이 다루는 카드들은 quotecards
